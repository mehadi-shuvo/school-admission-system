# AI Usage Disclosure

### 1. Tools Used

I used OpenAI Codex as an AI coding assistant. I cannot verify use of any other AI tool from the project history, so none is listed.

### 2. How AI Was Used

AI assisted with planning, implementation suggestions, debugging, tests, Docker and Nginx configuration, and documentation. It also helped review API contracts, concurrency rules, frontend error handling, and automated test coverage. I remained responsible for deciding what to keep, changing the code, and checking that it matched the assignment.

### 3. Mistakes and Limitations

No specific project error can be reliably attributed to AI from the available history. AI suggestions were not treated as proof that a solution was correct. In particular, environment-specific behaviour, Docker networking, and concurrency required source review and real test verification.

### 4. Review and Responsibility

I reviewed the implementation, configuration, documentation, and test reports before accepting changes. I used builds, backend and frontend tests, browser tests, and Docker health checks to verify behaviour. I remain responsible for the final submission and its accuracy.
